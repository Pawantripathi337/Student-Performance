# Smart Student Performance Prediction & Academic Analytics System

A Django web application that uses **supervised machine learning** to predict a student's final score, classify the performance level and flag academic risk, with an analytics dashboard and a searchable record store (SQLite).

> ⚠️ **Dataset note (read first):** the project ships with a **synthetic demo dataset** (`ml/dataset.csv`) that copies the column layout of the public UCI *Student Performance* dataset, so the app runs immediately. The rows are **not real students**. For your submission, switch to the real UCI file (see [Using the real UCI dataset](#using-the-real-uci-dataset)) and quote the metrics from *your* run.

---

## Features
- Modern landing page, prediction form with server-side validation, result page with explanation
- Predicted final score (%), performance category and rule-based risk level (Low / Medium / High)
- Rule-based improvement recommendations
- Dashboard: total/average/highest/lowest marks, average absences, risk counts, 5 Plotly charts + model comparison table & chart
- Records page with search, category/risk filters, sorting and pagination; detail page per student; delete
- Django Admin for stored predictions
- Friendly handling of empty fields, invalid/negative numbers, out-of-range marks, missing model or dataset

## Technologies
Python · Django · Pandas · NumPy · scikit-learn · Plotly.js (CDN) · Bootstrap 5 (CDN) · HTML/CSS/JavaScript · SQLite

## ML algorithms
| Task | Algorithms |
|---|---|
| Regression (final grade) | Linear Regression, Decision Tree Regressor, Random Forest Regressor |
| Classification (pass/fail) | Logistic Regression |

The best regressor is chosen automatically by the **lowest RMSE** on the test set. Metrics (MAE, MSE, RMSE, R²) are calculated by `ml/train_model.py` and saved to `ml/metrics.json` and `docs/MODEL_RESULTS.md`; nothing is hard-coded.

## Dataset
- **Bundled:** synthetic demo data, 600 rows × 14 columns (generated by `ml/generate_demo_dataset.py`, seed 42).
- **Recommended real data:** UCI Machine Learning Repository, *Student Performance* (P. Cortez & A. Silva, 2008), Portuguese secondary schools. Math file `student-mat.csv`, Portuguese file `student-por.csv` (`;`-separated). Check the row/column counts of the file you download and quote those.
- **Target:** `G3` – final grade (0–20); shown as a percentage (G3 × 5).

| Column | Meaning |
|---|---|
| age | Student age |
| sex | F / M |
| studytime | Weekly study time band: 1 = <2 h, 2 = 2–5 h, 3 = 5–10 h, 4 = >10 h |
| failures | Number of past class failures (0–3) |
| absences | Number of school absences |
| G1, G2 | Period 1 and Period 2 grades (0–20) – used as "previous marks" |
| schoolsup / famsup | Extra school / family educational support (yes/no) |
| activities | Extracurricular activities (yes/no) |
| internet | Internet access at home (yes/no) |
| freetime, goout | Free time after school / going out with friends (1–5) |

**Adaptations from the original brief:** the real dataset has no attendance percentage (we use `absences`), no assignment scores and no sleep hours, so those fields were not invented. G1/G2 predict G3 very strongly, so `docs/MODEL_RESULTS.md` also reports the models *without* G1/G2.

### Category boundaries
| Score | Category |
|---|---|
| 90–100 | Excellent |
| 75–89 | Good |
| 60–74 | Average |
| 40–59 | Needs Improvement |
| below 40 | Poor |

### Risk rules (`predictor/rules.py`)
Points are added for: predicted score < 75 / < 60 / < 40 (+1 / +2 / +3), 1 failure (+1) or 2+ failures (+2), absences > 8 (+1) or > 15 (+2), a drop of 2+ marks from Period 1 to 2 (+1), lowest study-time band (+1). **0–1 points = Low, 2–4 = Medium, 5+ = High.** This is a simple educational indicator, **not** a validated assessment.

## Installation
Requires Python 3.10+ (3.11+ recommended). Internet is needed in the browser for Bootstrap/Plotly CDNs.

```bash
# 1. open a terminal in the project folder
python -m venv venv

# 2. activate the virtual environment
venv\Scripts\activate            # Windows
source venv/bin/activate         # macOS / Linux

# 3. install dependencies
pip install -r requirements.txt

# 4. (optional) retrain the model on this computer
python ml/train_model.py

# 5. create the database
python manage.py migrate

# 6. (optional) create an admin user for /admin/
python manage.py createsuperuser

# 7. run the server
python manage.py runserver
```
Open http://127.0.0.1:8000/ . If `ml/model.pkl` was saved with a different scikit-learn version, the app retrains automatically on first use (or run step 4).

## How to use
1. **Predict** → fill the form → see score, category, risk, reasons and tips (record is saved).
2. **Dashboard** → dataset statistics, charts and model comparison.
3. **Records** → search, filter, sort; open a record for charts and suggestions.
4. **/admin/** → manage records.

## Using the real UCI dataset
1. Download *Student Performance* from the UCI repository and unzip it.
2. Copy `student-mat.csv` (or `student-por.csv`) to `ml/dataset.csv`.
3. Run: `python ml/train_model.py --source "UCI Student Performance (Math)"`
4. Restart `runserver`. The home page and dashboard now show the real row count and metrics.

## Tests
`python manage.py test` runs the tests in `predictor/tests.py` (pages load, valid/invalid prediction, search, 404).
